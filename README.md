# Workflow Intelligence Community Edition

Workflow Intelligence is an open-source toolkit for finding work worth investigating, validating workflow opportunities, and preserving evidence quality.

## What it does

Workflow Intelligence helps teams move from:

**Work observed → opportunity identified → evidence normalized → confidence assessed → decision made**

The Community Edition focuses on reusable workflow, evidence, opportunity, validation, and review primitives that can run locally.

## Quick start

```powershell
python -m pip install dist\workflow_intelligence-0.1.0-py3-none-any.whl
```

The release is source-first and self-hostable. See `docs/COMMUNITY_EDITION_SCOPE.md` for the exact public boundary.

## Evidence rules

- Never fabricate customers, validation, revenue, or outcomes.
- Synthetic evidence does not satisfy human-validation gates.
- Public business records are prospects, not proof of customer intent.
- Revenue claims require actual payment evidence.
- Human approval remains required before external execution.

## Commercial path

The Community Edition is intended to create adoption and trust. Commercial value is built around the core rather than by crippling it.

Community users can self-host the core; commercial offerings can add hosted operations, organizational administration, managed AI, governance, private deployment, support, implementation, and commercial integrations.
