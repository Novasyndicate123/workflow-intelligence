# Workflow Intelligence — Founding Proof-of-Value Pilot

## The offer

A fixed-scope engagement for a team that wants to know whether one repetitive workflow is worth automating before spending on implementation.

**Founding pilot price: A$499 fixed scope.**

This is a pricing hypothesis for early customer validation, not a claim that the market price is established.

## What the pilot includes

1. One real repetitive workflow supplied by the customer.
2. A structured workflow/evidence assessment using Workflow Intelligence Community Edition methods.
3. Economic opportunity analysis covering expected value, effort, complexity, control requirements, and key uncertainties.
4. A bounded experiment plan with a human-validation checkpoint.
5. A written proof-of-value report containing the evidence, decision, assumptions, and recommended next step.
6. One review session to walk through the result.

## What the pilot does not include

- Production automation implementation.
- Unapproved changes to customer systems.
- Guaranteed savings, ROI, or automation outcomes.
- Replacement of human approval for consequential decisions.

The pilot is intentionally a decision/proof service. The customer can use the resulting evidence to decide whether to build internally, use an existing automation platform, or continue with Workflow Intelligence services.

## Why this is the first paid product

The Community Edition stays free and self-hostable. The paid pilot monetizes expert-guided application of the methodology before we build a large hosted product.

This gives us a fast way to test three things with real buyers:

- whether the problem is important enough to pay to investigate;
- whether the evidence produced is useful for a real business decision;
- which hosted capabilities customers actually want next.

The A founding price is deliberately an entry-level proof step, not a full automation implementation. It is a market-test price and can change as real customer evidence accumulates.

## Conversion path

**Community Edition → Founding Proof-of-Value Pilot → Cloud / Business / Enterprise**

The pilot is the bridge between free adoption and paid recurring value.

## Evidence rule

A pilot counts as commercial validation only when there is an actual customer payment. Interest, a call, an email, a GitHub star, or a downloaded package is not revenue evidence.
